I like the Alls citation framing this as an SRP violation specifically, that the function is handling both iteration and discount decision logic at once. It's a slightly sharper way of naming the same problem I described as "long method with conditional logic," since it points at why the conditional chain is a problem, not just that it will get longer. A function violating SRP is harder to test in isolation, since you cannot verify the discount logic without also driving the iteration, which becomes more relevant as the function grows.
